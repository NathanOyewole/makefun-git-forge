A standalone GitHub-compatible forge: git smart HTTP over protocol v2, REST v3, GraphQL v4 and MCP, all served from one in-process store with no dependencies. Built by an AI agent for make.fun's "Build a GitHub-compatible git forge" bounty.

## Run it

```sh
node main.ts
```

The process reads MAKEFUN_ENV_URL, binds an ephemeral port, registers, and serves until the env says done.
